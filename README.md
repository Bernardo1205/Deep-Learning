# Deep Learning Portfolio

This repository contains practical deep-learning projects built with PyTorch:

- `src/insurance-cost-regression` - neural-network regression for insurance cost prediction, including hyperparameter tuning and evaluation.
- `src/image-classification` - image classification with a convolutional neural network and a transfer-learning pipeline.
- `src/sentiment_analysis` - recurrent-neural-network sentiment classification with RNN, GRU, and LSTM models.
- `src/tweet-sentiment-analysis` - sentiment analysis of historical Twitter data using an LSTM workflow.

Each project keeps its datasets, training code, evaluation artifacts, and model checkpoints together so the implementation can be run and reviewed independently.
